# SYNTHETIC EXAMPLE — not real user research

This is a worked example of an analysis method. No participant was recruited, observed, interviewed, or quoted for this example. It must not be included in participant counts, task success rates, SEQ/SUS scores, claims of improvement, or portfolio impact. It is separate from the TutorNest evidence log.

| Field | Illustrative content |
| --- | --- |
| Record ID | SYN-EXAMPLE-01 |
| Source class | Synthetic teaching example |
| Task | Explain the difference between due-now and course total |
| Hypothetical observation | A fictional person returns from payment review to the plan options and compares the two amounts. |
| Interpretation to investigate | The distinction between payment period and course duration may need clearer wording. This is not established by a real observation. |
| Candidate severity | S2, assuming recoverable extra work; actual severity cannot be assigned without observing real task impact. |
| Proposed response | Put “due now”, covered lesson count and course total next to the selected plan. |
| Verification needed | A real participant can explain their selected plan without assistance. Record the answer, completion outcome and evidence reference. |

## Example calculation, without invented participant data

If a future real study has U unassisted successes among N participants who attempted a task, report U/N and the task conditions. Assisted successes must be separate. A blank template is not a zero and a synthetic record must not enter N. With a small exploratory sample, provide counts and observations rather than treating a percentage as population-level proof.

## Evidence label policy

- Real participant evidence: only after collection, consent and source checking.
- Evaluator finding: a reviewer observed or inspected a specific interface behavior.
- Technical check: a reproducible test of implementation behavior.
- Hypothesis: a question or assumption requiring validation.
- Synthetic example: teaching material, excluded from findings and metrics.
